What it does

Four things a $80,000 analyst does, running all the time.

Natural language to SQL

Ask "who are my top 5 customers by spending?" — Sentris converts it to SQL with NVIDIA Nemotron Ultra 550B, runs it against your real database, and returns results.

Proactive anomaly detection

Automatically scans every table and column using Z-score analysis and week-over-week comparison. Finds problems nobody asked it to look for.

Auto-detecting charts

Query results render as line charts for time series, bar charts for comparisons, or plain tables — whichever fits the data best.

Works on any database

Auto-discovers every table and column in any connected PostgreSQL database. Tested on a custom demo database and the Chinook database, zero configuration.

Anomaly detection

Built on published statistical research, not guesswork.

The detection engine is based on IEEE research on Artificial Immune Systems by Peshal Ghanghas (IITCEE 2024). It auto-discovers tables with date and numeric columns — no hardcoding — then flags values more than 2 standard deviations from the mean, and any metric that dropped more than 40% week over week.

Z-score Severity
> 3.0 or < -3.0 High
> 2.5 or < -2.5 Medium
> 2.0 or < -2.0 Low

Spikes and drops are handled separately with distinct trending arrows. A full scan runs in under 3 seconds — AI explanations are generated on demand per anomaly, not in batch.

Architecture

What it's built on.

Backend

Python 3.13 + FastAPI, SQLAlchemy for connections, Pandas + SciPy for anomaly detection, sqlglot for SQL validation. SELECT-only enforced. Deployed on Render.

Frontend

React 18 + Vite, Tailwind CSS, Recharts for visualization, Lucide icons. Dark/light mode via CSS variables with animated gradient orbs. Deployed on Vercel.

Database & AI

PostgreSQL on Supabase with a session pooler. NVIDIA NIM infrastructure running Nemotron Ultra 550B for NL-to-SQL and anomaly explanations.

Security

Read-only by design, from day one.

Read-only enforcement

Only SELECT statements run. DROP, DELETE, INSERT, UPDATE, ALTER and TRUNCATE are all blocked.

SQL validation

sqlglot parses every generated query before it reaches the database, catching syntax errors first.

Credentials

Database URLs are never stored or logged. The connection field uses type="password".

CORS

Restricted to specific Vercel and localhost origins only.
